## 📂 Task 3 — File Automation

A Python automation program that identifies `.jpg` images from one folder and moves them automatically into an organized destination folder.

### Concepts Used

* `os` module
* `shutil` module
* File handling
* Directory handling
* Loops
* Conditional statements

### Folder Structure

```text
Project
│
├── task3_file_automation.py
│
├── photo_collection/
│   ├── image1.jpg
│   ├── image2.jpg
│   └── image3.jpg
│
└── organized_photos/
```

### Features

* Automatically creates required folders
* Detects JPG images
* Moves images automatically
* Displays the number of files processed
* Organizes files without manually moving them

**Source Code:** `task3_file_automation.py`
